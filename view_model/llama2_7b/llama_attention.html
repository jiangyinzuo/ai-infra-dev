Causal Mask

LLaMA 的 causal mask 让 𝑗>𝑖 的位置变成 −∞：

        k1   k2   k3   k4
   q1 │ s11  -∞   -∞   -∞ │
   q2 │ s21  s22  -∞   -∞ │
   q3 │ s31  s32  s33  -∞ │
   q4 │ s41  s42  s43  s44│
  • 第 𝑖 行只有前 𝑖 列有效；
  • 第 𝑖 个 query 只能看到 𝑗≤𝑖 的 key。

变成−∞后， 再经过softmax ，这些位置的权重精确为 0。

Softmax归一化

softmax 的输入被称为logits。 除以𝑑是为了把点积的方差从𝑑拉回1，防止 softmax 饱和、梯度消失和数值溢出。

归一化通用形式： 𝛼𝑖=𝑓(𝑧𝑖)∑𝑗𝑓(𝑧𝑗)

  • 𝑓(𝑧)=𝑧：普通归一化（保持比例）
  • 𝑓(𝑧)=𝑒𝑧：softmax归一化（放大差异）
  • 𝑓(𝑧)=max(𝑧,0)：ReLU 归一化

示例：𝑧=(1,2,3)

  • 普通归一化：(1/6,2/6,3/6)=(0.167,0.333,0.500)，比例仍是 1:2:3；
  • softmax：(0.090,0.245,0.665)，比例变成 1:2.7:7.4，差距被拉大。

Attention 是置换等变的

假设没有 causal mask，对输入做任意置换 𝑃（打乱 token 顺序）：

𝑋′=𝑃𝑋

那么：

𝑄′=𝑃𝑋𝑊𝑄=𝑃𝑄𝐾′=𝑃𝐾,𝑉′=𝑃𝑉

代入注意力：

Attn(𝑄′,𝐾′,𝑉′)=softmax(𝑃𝑄𝐾𝑇𝑃𝑇𝑑𝑘)𝑃𝑉=𝑃⋅softmax(𝑄𝐾𝑇𝑑𝑘)𝑉=𝑃⋅Attn(𝑄,𝐾,𝑉)

Attn(𝑃𝑋)=𝑃⋅Attn(𝑋)

这叫置换等变：打乱输入顺序，输出只是被同样打乱，内容完全不变。

二维向量的旋转矩阵

假设有一个二维向量：𝐯=(𝑥,𝑦)，向量长度是𝑟=𝑥2+𝑦2。

现在把这个向量绕原点逆时针旋转 𝜃 角，得到新向量：𝐯′=(𝑥′,𝑦′)

旋转过程中有两个重要性质：

  1. 长度不变：|𝐯′|=|𝐯|=𝑟。
  2. 方向变了：原来的角度加上 𝜃，变成新的角度。
旋转公式推导

原来的向量可以写成：𝑥=𝑟cos𝛼, 𝑦=𝑟sin𝛼， 其中 𝛼 是原向量和 x 轴的夹角。

旋转 𝜃 后，新角度是：𝛼+𝜃。

所以， 𝑥′=𝑟cos(𝛼+𝜃)，𝑦′=𝑟sin(𝛼+𝜃)

用三角和角公式展开：

𝑥′=𝑟(cos𝛼cos𝜃−sin𝛼sin𝜃)𝑦′=𝑟(sin𝛼cos𝜃+cos𝛼sin𝜃)

代入：𝑥=𝑟cos𝛼,𝑦=𝑟sin𝛼

得到：

𝑥′=𝑥cos𝜃−𝑦sin𝜃𝑦′=𝑥sin𝜃+𝑦cos𝜃

这就是二维旋转公式。

写成矩阵形式
(𝑥′𝑦′)=(cos𝜃−sin𝜃sin𝜃cos𝜃)(𝑥𝑦)

RoPE核心原理

LLaMA 中的 RoPE (Rotary Position Embedding) 通过一种旋转操作将位置信息融入注意力机制。它的核心思想是：对 Query (Q) 和 Key (K) 向量的维度进行成对旋转，旋转的角度由该 token 的绝对位置决定。这样一来，当计算两个 token 的 Q 和 K 的点积时，其结果会自然地只依赖于它们的相对位置。

RoPE 会把一个高维向量拆成很多二维子空间，例如：

q = [ q0, q1, q2, q3, q4, q5, ... ]

可以看成：

(q0, q1)  → 一个二维平面
(q2, q3)  → 另一个二维平面
(q4, q5)  → 另一个二维平面
...

对每一对维度做旋转：

(𝑞2𝑖′𝑞2𝑖+1′)=(cos(𝑚𝜃𝑖)−sin(𝑚𝜃𝑖)sin(𝑚𝜃𝑖)cos(𝑚𝜃𝑖))(𝑞2𝑖𝑞2𝑖+1)

其中：

  • 𝑚 是 token 的位置；
  • 𝜃𝑖 是这一对维度对应的固定频率；
  • 𝑚𝜃𝑖 就是旋转角度。
  • 𝜃𝑖=10000−2𝑖/𝑑（LLaMA 3将10000调为500000，支持更长的上下文）

RoPE保持相对位置不变，旋转后向量的点积只取决于角度差(𝑚−𝑛)𝜃

  1. 旋转不改变向量长度：所以 RoPE 只改变方向，不改变 Q/K 的尺度；
  2. 两个旋转后的向量做点积时，位置信息只以“旋转角之差”的形式出现；
  3. 因为旋转角分别是 𝑚𝜃 和 𝑛𝜃，所以“角度差”自然变成 (𝑚−𝑛)𝜃，也就是相对位置。

假设某个 Query 向量和 Key 向量在二维平面里分别是：

𝑞=(𝑟𝑞cos𝛼,𝑟𝑞sin𝛼),𝑘=(𝑟𝑘cos𝛽,𝑟𝑘sin𝛽)

其中：

  • 𝑟𝑞,𝑟𝑘 是长度；
  • 𝛼,𝛽 是它们原来的方向角。

现在 Query 在位置 𝑚，Key 在位置 𝑛。RoPE 对它们分别旋转：

𝑞′=𝑅(𝑚𝜃)𝑞𝑘′=𝑅(𝑛𝜃)𝑘

其中 𝑅(⋅) 是二维旋转矩阵。

旋转后：

  • 𝑞′ 的方向角变成 𝛼+𝑚𝜃；
  • 𝑘′ 的方向角变成 𝛽+𝑛𝜃。

两个向量的点积等于：

𝑞′⋅𝑘′=|𝑞′||𝑘′|cos(两个向量的夹角)

而旋转保持长度不变，所以：

|𝑞′|=𝑟𝑞,|𝑘′|=𝑟𝑘

两个旋转后向量的夹角是：

(𝛼+𝑚𝜃)−(𝛽+𝑛𝜃)=(𝛼−𝛽)+(𝑚−𝑛)𝜃

因此：

𝑞′⋅𝑘′=𝑟𝑞𝑟𝑘cos((𝛼−𝛽)+(𝑚−𝑛)𝜃)

注意看这个结果：

  • 𝛼−𝛽 来自 Query 和 Key 的内容方向差；
  • (𝑚−𝑛)𝜃 来自位置差；
  • 单独的 𝑚 和 𝑛 没有出现，只有 𝑚−𝑛。

所以对于固定的 𝑞,𝑘，点积只依赖相对位置 𝑚−𝑛。

用矩阵解释

二维旋转矩阵是：

𝑅(𝜃)=(cos𝜃−sin𝜃sin𝜃cos𝜃)

它有一个关键性质：

𝑅(𝑎)𝑇𝑅(𝑏)=𝑅(𝑏−𝑎)

也就是说，两个旋转矩阵的“相对作用”只取决于角度差。

RoPE 后：

𝑞′=𝑅(𝑚𝜃)𝑞𝑘′=𝑅(𝑛𝜃)𝑘

点积为：

𝑞′𝑇𝑘′=𝑞𝑇𝑅(𝑚𝜃)𝑇𝑅(𝑛𝜃)𝑘

利用上面的性质：

𝑅(𝑚𝜃)𝑇𝑅(𝑛𝜃)=𝑅(𝑛𝜃−𝑚𝜃)=𝑅((𝑛−𝑚)𝜃)

所以：

𝑞′𝑇𝑘′=𝑞𝑇𝑅((𝑛−𝑚)𝜃)𝑘

右边只出现：

𝑛−𝑚

也就是相对位置。如果令：

Δ=𝑚−𝑛

那么点积就是 Δ 的函数：

𝑞′𝑇𝑘′=𝐹(𝑞,𝑘,Δ)

更准确地说：

Query 和 Key 的内容 𝑞,𝑘 仍然会影响点积；但位置部分只通过相对位移 Δ=𝑚−𝑛 进入点积。
“保持长度不变”的作用

旋转矩阵是正交矩阵，满足：

𝑅(𝜃)𝑇𝑅(𝜃)=𝐼

所以：

∥𝑅(𝜃)𝑥∥=∥𝑥∥

也就是：

旋转只改变方向，不改变长度

这有几个意义：

  1. 不会因为位置编码把 Q/K 的数值放大或缩小
    RoPE 不是给向量加一个位置向量，而是把向量旋转。范数不变，注意力的尺度更稳定。

  2. 点积公式可以写成“长度 × 夹角余弦”
    因为长度不变，两个旋转后向量的点积变化完全来自夹角变化。

  3. 位置信息只影响方向，不干扰内容幅值
    模型仍然可以通过 Q/K 的长度表达内容强度，而位置只改变方向。

不过要注意：
“保持长度不变”本身不是相对位置编码的根本原因；根本原因是：

𝑅(𝑚𝜃)𝑇𝑅(𝑛𝜃)=𝑅((𝑛−𝑚)𝜃)

也就是两个旋转的相对旋转只依赖角度差。长度保持让这个几何解释更干净、数值更稳定。

高维 RoPE

LLaMA 的 Q/K 不是二维，而是比如 128 维。RoPE 把它拆成很多二维对：

(𝑞0,𝑞1),(𝑞2,𝑞3),(𝑞4,𝑞5),…

每一对用一个固定频率 𝜃𝑖 旋转：

𝜃𝑖=10000−2𝑖/𝑑

对于位置 𝑚，第 𝑖 对维度的旋转角是：

𝑚𝜃𝑖

对于位置 𝑛，第 𝑖 对维度的旋转角是：

𝑛𝜃𝑖

于是整个高维 Q/K 的 RoPE 可以写成块对角旋转：

𝑅𝑚=diag(𝑅(𝑚𝜃0),𝑅(𝑚𝜃1),…,𝑅(𝑚𝜃𝑑/2−1))

那么：

𝑞′=𝑅𝑚𝑞,𝑘′=𝑅𝑛𝑘

点积为：

𝑞′𝑇𝑘′=𝑞𝑇𝑅𝑚𝑇𝑅𝑛𝑘

由于每个二维块都满足：

𝑅(𝑚𝜃𝑖)𝑇𝑅(𝑛𝜃𝑖)=𝑅((𝑛−𝑚)𝜃𝑖)

所以：

𝑞′𝑇𝑘′=∑𝑖𝑞𝑖𝑇𝑅((𝑛−𝑚)𝜃𝑖)𝑘𝑖

这个结果仍然是：

𝐹(𝑞,𝑘,𝑚−𝑛)

也就是说：

高维 RoPE 中，QK 点积的位置部分由多个频率的“相对旋转”叠加而成，但整体仍然只依赖相对位置 𝑚−𝑛。

它不是只依赖一个角度，而是依赖一组相对角度：

(𝑛−𝑚)𝜃0,(𝑛−𝑚)𝜃1,…

但这些角度全都由同一个相对位移 𝑚−𝑛 决定。

“相对位置编码”的含义

假设有两个 token：

  • Query 在位置 𝑚；
  • Key 在位置 𝑛。

注意力分数大致是：

score(𝑚,𝑛)=𝑞𝑚𝑇𝑘𝑛

经过 RoPE 后：

score(𝑚,𝑛)=𝐹(𝑞𝑚,𝑘𝑛,𝑚−𝑛)

这意味着：

  • 模型不需要直接知道“这是第 5 个 token、那是第 9 个 token”；
  • 它通过 QK 点积看到的是“这两个 token 相距 4 个位置”这种相对关系；
  • 如果把所有 token 的位置同时平移一个常数 𝑐，即：
𝑚→𝑚+𝑐,𝑛→𝑛+𝑐

那么：

(𝑚+𝑐)−(𝑛+𝑐)=𝑚−𝑛

相对位置不变，因此 QK 点积不变。

这就是“相对位置编码”的核心：

绝对位置：m, n
        ↓ RoPE 分别旋转
旋转角：mθ, nθ
        ↓ 点积只看角度差
相对位置：m-n
一个容易误解的点

“点积只取决于旋转角度之差”这句话要加一个前提：

对于固定的原始 𝑞,𝑘 向量，位置部分只取决于旋转角之差。

完整的注意力分数当然还依赖 Q/K 的内容：

score=𝐹(内容𝑞,内容𝑘,相对位置)

不是“只依赖相对位置”。更准确的说法是：

RoPE 让位置信息以相对位移的形式进入 QK 点积，而不是以绝对位置 𝑚 或 𝑛 的形式进入。
总结

二维旋转满足：

𝑅(𝑚𝜃)𝑇𝑅(𝑛𝜃)=𝑅((𝑛−𝑚)𝜃)

所以 RoPE 后：

(𝑅(𝑚𝜃)𝑞)𝑇(𝑅(𝑛𝜃)𝑘)=𝑞𝑇𝑅((𝑛−𝑚)𝜃)𝑘

右边只出现 𝑛−𝑚，不单独出现 𝑚 或 𝑛。同时旋转保持长度：

∥𝑅(𝜃)𝑥∥=∥𝑥∥

因此 RoPE 只改变 Q/K 的方向，不改变尺度，并让 QK 点积中的位置部分自然变成相对位置 𝑚−𝑛 的函数。高维 RoPE 只是把这件事在很多二维子空间上并行做了一遍。

RoPE 为什么要用多频率旋转编码位置

RoPE 不是只用一个角度编码位置，而是把 Q/K 向量拆成多个二维子空间，每个子空间用不同频率 𝜃𝑖 旋转。这样做的本质是：用一组不同频率的旋转共同编码相对位置，形成多尺度、多分辨率的位置表示。

1. 每个 𝜃𝑖 是一个二维子空间的“角速度”

LLaMA 把 Q/K 向量拆成若干二维对：

(𝑞0,𝑞1),(𝑞2,𝑞3),(𝑞4,𝑞5),…

第 𝑖 对维度使用频率 𝜃𝑖。位置为 𝑚 的 token，其第 𝑖 对的旋转角为：

angle𝑖(𝑚)=𝑚𝜃𝑖

其中：

𝜃𝑖=10000−2𝑖/𝑑

因此不同维度对的“角速度”不同：

  • 𝑖=0 时，𝜃0=1，旋转最快；
  • 𝑖 越大，𝜃𝑖 越小，旋转越慢；
  • 最后一对维度频率最低，周期最长。

如果所有维度都用同一个 𝜃，所有二维对会同步旋转，位置编码就退化成“只有一个指针的钟”。

2. 多频率使 QK 点积成为相对位置的多频率函数

经过 RoPE 后，Query 在位置 𝑚，Key 在位置 𝑛。令相对位置差为 Δ=𝑚−𝑛，则 QK 点积中第 𝑖 个二维子空间的贡献可写成：

𝑞𝑖𝑇𝑅((𝑛−𝑚)𝜃𝑖)𝑘𝑖

其位置相关部分由 cos(Δ𝜃𝑖)、sin(Δ𝜃𝑖) 组成。整个 QK 点积的位置部分是多个频率项之和：

∑𝑖[cos(Δ𝜃𝑖)(𝑞2𝑖𝑘2𝑖+𝑞2𝑖+1𝑘2𝑖+1)+sin(Δ𝜃𝑖)(⋯)]

也就是说，相对位置 Δ 不是只通过一个角度进入模型，而是通过一组不同频率的三角函数进入模型：

Δ𝜃0,Δ𝜃1,Δ𝜃2,…

这比单一频率的表达能力强得多。

3. 如果所有维度同频会怎样

假设所有 𝜃𝑖=𝜃，则整个 Q/K 向量相当于被同一个旋转矩阵旋转：

𝑞′=𝑅(𝑚𝜃)𝑞,𝑘′=𝑅(𝑛𝜃)𝑘

点积只通过一个角度差进入：

𝑞′𝑇𝑘′=𝑞𝑇𝑅((𝑛−𝑚)𝜃)𝑘

于是位置信息只表现为：

Δ𝜃mod2𝜋

这带来两个问题。

问题一：周期性强，容易混淆

旋转是周期性的：

𝑅(Δ𝜃)=𝑅(Δ𝜃+2𝜋)

所以 Δ 和 Δ+2𝜋𝜃 会产生完全相同的旋转。模型无法区分相差一个周期的位置差。

例如 𝜃=1 时，位置差 0 和 2𝜋≈6.28 在旋转上无法区分。

问题二：无法同时兼顾近距和远距分辨率
  • 频率太高：相邻位置区分明显，但很快周期重复，远距离混淆；
  • 频率太低：远距离不混淆，但相邻位置几乎转不动，近距离分辨率差。

单一频率无法同时做好“局部精细”和“长程区分”。

4. 多频率组合相当于多尺度计数

可以用时钟类比：

  • 秒针转得快，负责精细时间；
  • 分针转得慢，负责中等尺度；
  • 时针转得更慢，负责大尺度。

只看秒针，不知道过了多少小时；只看时针，分不清几秒。三者组合，才能在大范围内唯一确定时间。

RoPE 的多频率也是同样道理：

  • 高频 𝜃𝑖 大：波长短，擅长区分邻近位置；
  • 低频 𝜃𝑖 小：波长长，擅长区分远距离；
  • 多个频率组合：在很大范围内形成较唯一的相对位置模式。

单频时，混淆条件是：

Δ𝜃=2𝜋𝑘

多频时，要同时混淆需要：

Δ𝜃𝑖=2𝜋𝑘𝑖,∀𝑖

这通常对应大得多的周期，因此可区分范围大大增加。

5. 为什么用几何级数 10000−2𝑖/𝑑

𝜃𝑖 对应的波长为：

𝜆𝑖=2𝜋𝜃𝑖=2𝜋⋅100002𝑖/𝑑

因此：

  • 𝑖=0：𝜆0≈2𝜋≈6.28，高频、短波长；
  • 𝑖 增大：波长按几何级数增长；
  • 最大波长约为：
2𝜋⋅10000≈6.28×104

这样频率在对数尺度上均匀分布，覆盖从“几个 token”到“几万个 token”的多个尺度。这种设计来自原始 Transformer 的正弦位置编码，LLaMA 沿用并用于旋转。底数 10000 是经验超参；LLaMA 3 改成 500000，是为了让最低频周期更长，从而支持更长上下文。

6. 同频问题的具体例子

取一个极简例子：

  • head_dim = 4，共有 2 对二维子空间：(𝑞0,𝑞1) 和 (𝑞2,𝑞3)；
  • 取 𝑞=𝑘=(1,1,1,1)；
  • 先假设所有维度对都用同一个频率 𝜃=1。

对任意一对维度，RoPE 后点积的位置部分为：

(𝑞2𝑖𝑘2𝑖+𝑞2𝑖+1𝑘2𝑖+1)cos(Δ𝜃𝑖)+(𝑞2𝑖𝑘2𝑖+1−𝑞2𝑖+1𝑘2𝑖)sin(Δ𝜃𝑖)

代入 𝑞=(1,1)、𝑘=(1,1)，有：

𝑞0𝑘0+𝑞1𝑘1=2,𝑞0𝑘1−𝑞1𝑘0=0

所以每一对维度的贡献简化为：

2cos(Δ𝜃𝑖)
情况 A：所有维度同频 𝜃=1

两对维度完全相同，总 QK 位置分数为：

𝑆𝐴(Δ)=2cos(Δ)+2cos(Δ)=4cos(Δ)

这是一个周期为 2𝜋 的函数。因此：

𝑆𝐴(0)=𝑆𝐴(2𝜋)=𝑆𝐴(4𝜋)=…=4

模型完全无法区分“位置差 0”“位置差 6.28”“位置差 12.57”。同样：

𝑆𝐴(1)=𝑆𝐴(1+2𝜋)=𝑆𝐴(1+4𝜋)

也无法区分。

也就是说，单一频率的位置编码以 2𝜋/𝜃 为周期重复。𝜃=1 时，周期只有约 6.28 个 token，超过 6 个 token 的相对位置就开始“撞车”。

由于token的位置是整数，周期等于6.28不会严格撞车，但有近似重复、分辨率低的问题。 如果要严格撞车，周期需要是整数，但RoPE 实际使用：𝜃𝑖=10000−2𝑖/𝑑， 对应周期：2𝜋𝜃𝑖=2𝜋⋅100002𝑖/𝑑。 这些周期通常不是整数，所以对整数位置差而言，严格周期撞车并不常见。但单频的问题仍然存在，只是表现形式变成：

  • 高频维度周期短，局部模式很快近似重复；
  • 低频维度转得慢，近距离分辨率差；
  • 单一频率无法同时提供多尺度信息；
  • 多频组合把“严格或近似混淆”推到更远的距离。
情况 B：用多频率 𝜃0=1,𝜃1=0.01

总分数变为：

𝑆𝐵(Δ)=2cos(Δ×1)+2cos(Δ×0.01)

计算几个位置差：

Δ2cos(Δ)2cos(0.01Δ)𝑆𝐵(Δ)
0224.000
2𝜋≈6.2832≈1.996≈3.996
4𝜋≈12.5662≈1.984≈3.984
1≈1.081≈1.9999≈3.081
1+2𝜋≈7.283≈1.081≈1.9947≈3.076

现在：

  • Δ=0：𝑆𝐵=4.000；
  • Δ=2𝜋：𝑆𝐵=3.996，不再相等；
  • Δ=4𝜋：𝑆𝐵=3.984，继续不同。

高频那一对在 Δ=2𝜋 处已经“转回原点”，但低频那一对只转了 0.0628 弧度，还远没转回来。两对组合后，整体分数不再周期性重复。

多频率把这个“单周期”打散成一组不同周期的叠加：

Δ𝜃0,Δ𝜃1,…,Δ𝜃𝑑/2−1

要让所有频率同时回到原点，需要 Δ 同时满足：

Δ𝜃𝑖≡0(mod2𝜋),∀𝑖

这要求 Δ 是所有 2𝜋/𝜃𝑖 的公倍数。由于 𝜃𝑖 按几何级数分布，这个公倍数极大，在实际上下文长度内基本不会发生。这就是多频率能大幅扩展可区分位置范围的原因。

7. 总结

不同维度使用不同 𝜃𝑖，是为了让 RoPE 用多个频率的旋转共同编码相对位置：

Δ𝜃0,Δ𝜃1,…

高频负责近距精细分辨，低频负责长程区分，组合起来形成多尺度位置表示。如果所有维度同频，位置编码会退化成单一正弦波，周期只有 2𝜋/𝜃，周期性强、分辨率单一、表达能力弱。RoPE 用几何级数分布的频率 𝜃𝑖=10000−2𝑖/𝑑，把“周期撞车”推到极远的位置差上，从而实现长程可区分的位置编码。

LLaMA 中的具体实现：rotate_half

在实际的 LLaMA 代码实现中，为了高效计算，通常不会显式地构造旋转矩阵，而是采用一种称为 rotate_half 的向量化操作。 rotate_half和原始RoPE计算结果完全等价。

假设一个头维度 head_dim 为 𝑑 的向量 x，其整体计算可以简洁地表示为：

RoPE(𝑥)=𝑥⊙cos+rotate_half(𝑥)⊙sin

其中，⊙ 表示逐元素乘法。关键在于 rotate_half 函数的操作：

  1. 分割：将向量 x 沿最后一维平均分成两半，得到前半部分 𝑥first 和后半部分 𝑥second。

    𝑥=[𝑥first∣𝑥second]

  2. 构造旋转：rotate_half(x) 的结果是将后半部分取负，前半部分保持原样，然后交换位置。

    rotate_half(𝑥)=[−𝑥second∣𝑥first]

    这个操作等价于对向量的每一个二维子空间进行 90 度的旋转，再与预先计算好的 cos 和 sin 表相乘，就能组合出任意角度的旋转效果。

这种实现方式可以完全利用现有的矩阵乘法和逐元素运算来完成，无需编写特殊的内核，因此在 LLaMA、GPT-NeoX、Mistral 等模型中被广泛采用。
