DCP 下的 Prefill

普通 MLA 的 forward_mha 路径。PCP=1，Prefill 实例 TP=2, DCP=2。

此配置下 Prefill 的 TP 组和 DCP 组成员相同，TP rank 0、1 各自对应 DCP rank 0、1。

混部和分离使用同一条 Prefill 路径

Chunked Prefill 可以把 prompt 分到多个调度步。本例 8 个 prompt token 没有前缀命中，每步分到 4 个 token 的预算，所以分两轮。若一步能分到 8 个 token，整段一轮完成。

每轮两个 TP rank 都处理本轮全部 token，Q heads 按 TP 切分。压缩主 KV 按页交错写入，每页含 2 个 token。B0–B3 是 prompt 内的逻辑页序号，颜色标记写入该页的 Prefill TP rank。

Q(t0–t3) 读取本轮投影得到的 K/V(t0–t3)。历史长度为 0，直接得到本轮输出。
