Online Softmax

Online Softmax 是 Flash Attention 的核心数学机制。其基本思想是将完整的 Softmax 计算拆分为多个 Block，通过维护少量中间统计量，实现分块、增量式计算，而无需物化完整的 Attention Score Matrix 和 Probability Matrix。

初始计算

设当前 Query Block 包含 𝐵𝑞 个 Query Row，Query/Key 的 Head Dimension 为 𝑑，Value 的 Head Dimension 为 𝑑𝑣。令第 𝑗 个 Key/Value Block 包含 𝐵𝑘,𝑗 个 Token（𝑗=1,…,𝑇），则

𝑄∈ℝ𝐵𝑞×𝑑
𝐾𝑗∈ℝ𝐵𝑘,𝑗×𝑑𝑉𝑗∈ℝ𝐵𝑘,𝑗×𝑑𝑣

其中 𝐾𝑗 与 𝑉𝑗 沿序列维度对齐，即二者具有相同的行数 𝐵𝑘,𝑗。将所有 KV Block 沿序列维度拼接，记

𝐾=[𝐾1;𝐾2;…;𝐾𝑇]∈ℝ𝑁𝑘×𝑑
𝑉=[𝑉1;𝑉2;…;𝑉𝑇]∈ℝ𝑁𝑘×𝑑𝑣

其中

𝑁𝑘=∑𝑗=1𝑇𝐵𝑘,𝑗.

因此，第 𝑗 个 KV Block 产生的局部 Attention Score 为

𝑆𝑗=𝑄𝐾𝑗𝑇𝑑∈ℝ𝐵𝑞×𝐵𝑘,𝑗.

其中 𝐾𝑗𝑇∈ℝ𝑑×𝐵𝑘,𝑗，所以矩阵乘法的维度为

(𝐵𝑞×𝑑)(𝑑×𝐵𝑘,𝑗).

完整的 Score Matrix 按列拼接为

𝑆=[𝑆1,𝑆2,…,𝑆𝑇]∈ℝ𝐵𝑞×𝑁𝑘,

但 Online Softmax 不需要将其整体物化。

Online Softmax 为每个 Query Row 维护三个统计量：

  • 𝑚：当前已处理 Score 的最大值。
  • 𝑙：以当前最大值为基准的指数和。
  • 𝑢：以当前最大值为基准的加权 Value 累积结果。

初始化：

𝑚0=−∞
𝑙0=0
𝑢0=0

其中 𝑚0 和 𝑙0 的形状均为 𝐵𝑞×1，𝑢0 的形状为 𝐵𝑞×𝑑𝑣。上述统计量均按 Query Row 独立维护。

递推计算

对于第 𝑗 个 KV Block，首先计算局部 Score：

𝑆𝑗=𝑄𝐾𝑗𝑇𝑑

计算当前 Block 每个 Query Row 的局部最大值：

𝑚𝑗local=rowmax(𝑆𝑗)

更新全局最大值：

𝑚𝑗=max(𝑚𝑗−1,𝑚𝑗local)

由于最大值发生变化，需要将历史统计量重新缩放到新的最大值基准下。定义两个缩放系数：

𝛼𝑗=exp(𝑚𝑗−1−𝑚𝑗)
𝛽𝑗=exp(𝑚𝑗local−𝑚𝑗)

更新指数和：

𝑙𝑗=𝛼𝑗𝑙𝑗−1+𝛽𝑗rowsum(exp(𝑆𝑗−𝑚𝑗local))

更新加权 Value 累积结果：

𝑢𝑗=𝛼𝑗𝑢𝑗−1+𝛽𝑗exp(𝑆𝑗−𝑚𝑗local)𝑉𝑗

其中 𝛼𝑗 和 𝛽𝑗 均按 Query Row 广播，指数运算为逐元素运算。

最终输出

当所有 𝑇 个 KV Block 处理完毕后，得到最终统计量：

𝑚𝑇,𝑙𝑇,𝑢𝑇

最终 Attention Output 为：

𝑂=𝑢𝑇𝑙𝑇

其中除法按照 Query Row 在 Value Dimension 上进行广播。

同时，可以计算每个 Query Row 对应的 Log-Sum-Exp（LSE）：

LSE=𝑚𝑇+log(𝑙𝑇)

LSE 表示原始 Attention Score 的指数和的对数：

LSE𝑖=log(∑𝑗exp(𝑆𝑖,𝑗))

因此，Softmax Probability 可以通过以下公式恢复：

𝑃𝑖,𝑗=exp(𝑆𝑖,𝑗−LSE𝑖)

数学意义

Online Softmax 的关键在于：每次处理新的 KV Block 时，通过更新全局最大值 𝑚，并利用缩放系数 𝛼 和 𝛽 对历史统计量进行重标定，从而保证增量计算结果与完整 Softmax 在数学上等价。

整个计算过程中，只需要维护 𝑚、𝑙 和 𝑢 三个中间统计量，无需保存完整的 𝑁×𝑁 Attention Score Matrix 或 Probability Matrix。

此外，(𝑚,𝑙,𝑢) 还可以通过相同的重标定公式进行合并，因此支持不同 KV Partition 上的并行计算与分布式 Reduce。这也是 Online Softmax 能够应用于 Context Parallelism、Ring Attention 和 Flash-Decoding 等技术的重要数学基础。

一个实现细节： 上述初始化中的 𝑚0=−∞ 是数学上的初始状态。实际 GPU/NPU Kernel 中通常会对首个有效 Block 做特殊处理，避免直接计算 exp(−∞−(−∞)) 产生 NaN。
